# Knowledge Is Not Evidence

Knowledge is synthesized understanding: concepts, terminology, literature interpretations, reusable methods, and relationships that have survived review. Evidence is a traceable observation or result connected to a source, method, configuration, run, and interpretation boundary.

They strengthen each other but cannot substitute for each other. Knowledge helps design an experiment and interpret its result. Evidence can challenge existing knowledge or support a candidate synthesis. Copying a summary into a project does not create evidence; copying raw output into a vault does not create understanding.

The Vault owns reviewed cross-project knowledge. The Design Lab owns project evidence and the executable context needed to assess it. Promotion between them is explicit and preserves provenance.
