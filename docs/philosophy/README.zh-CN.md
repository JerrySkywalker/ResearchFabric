# ResearchFabric 理念

ResearchFabric 从一个简单问题出发：AI 可以提高研究工作的速度，却也可能让连续性、来源和权威更容易丢失。解决方案不是把聊天记录当成实验室，也不是让自治智能体凌驾于科学判断之上。
