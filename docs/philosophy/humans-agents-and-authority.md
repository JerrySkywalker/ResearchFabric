# Humans, Agents, and Authority

Capability and authority are different. An agent can produce an excellent recommendation without having authority to adopt it. A successful run can produce evidence without deciding what the evidence means for a project.

ResearchFabric keeps these transitions explicit. Agents act within admitted scope and label uncertainty, assumptions, inference, and results. Humans retain scientific judgment and Owner authority. A hypothesis becomes adopted project state only through a recorded decision; a synthesis becomes shared knowledge only through deliberate review and promotion.

This protects both directions: humans can use strong automation without surrendering authority, and agents can work effectively without pretending to possess it.
