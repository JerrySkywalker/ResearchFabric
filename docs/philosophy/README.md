# ResearchFabric Philosophy

ResearchFabric starts from a simple problem: AI can increase the speed of research work while making continuity, provenance, and authority easier to lose. The answer is not to treat a chat transcript as a laboratory or to place an autonomous agent above scientific judgment.

These essays describe the intended alternative:

- [AI4S and agent-native research](ai4s-and-agent-native-research.md)
- [Knowledge versus evidence](knowledge-vs-evidence.md)
- [Humans, agents, and authority](humans-agents-and-authority.md)
- [Git-native research](git-native-research.md)
- [Provider and machine independence](provider-machine-independence.md)
- [Non-goals](non-goals.md)
