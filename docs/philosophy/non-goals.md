# Non-Goals

ResearchFabric does not aim to:

- replace scientists or automate scientific authority;
- treat LLM output, a commit, or a passing check as evidence by itself;
- centralize every bibliography, attachment, large asset, or tool database in Git;
- synchronize templates and instances automatically;
- become a third Template Pair component, monorepo, runtime service, or control plane;
- require a knowledge graph, terminology database, daemon, MCP layer, or other middleware before a demonstrated need;
- prescribe one AI provider, agent implementation, operating system, or research discipline.

The project provides durable conventions and composable templates, not a claim that one repository can contain science.
