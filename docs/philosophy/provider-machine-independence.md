# Provider and Machine Independence

Research identity should not be bound to one AI provider, local agent, workstation, chat, or execution substrate. Those things will change more quickly than a serious research program.

Portable text, explicit schemas, relative repository paths, logical asset identities, stable source identifiers, and reproducible commands reduce accidental coupling. Provider-specific workflows can exist below the boundary, but their session IDs or proprietary graphs should not become canonical scientific identity.

Independence does not mean every environment is identical. It means a new environment can discover the state, understand its authority, and continue without reconstructing the project from private memory.
