# Git-Native Research

Git is useful for compact research state that benefits from history, review, attribution, branching, and portable identity. It is well suited to methods, code, configuration, metadata, registers, decisions, and selected compact evidence.

Git is not proof. A commit can preserve who changed a claim and when, but cannot establish that a method was sound or a conclusion true. Scientific assurance still requires source quality, reproducible methods, evidence, criticism, verification, and explicit decisions.

Nor must all data live in Git. Citation databases, managed attachments, raw sweeps, large simulations, and instrument stores can remain in native systems. Git should record stable references and the provenance needed to find and interpret them.
