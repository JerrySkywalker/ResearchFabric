# 架构概览

ResearchFabric 将持久研究职责分开，使每类状态都有明确权威。

```text
参考文献权威（例如 Zotero）                  持久大型资产权威
                    \                         /
                         引用与稳定标识
                              |
研究知识库模板 <--- 经审查的晋升与引用 ---> 研究设计实验室模板
跨项目知识                                  项目执行与证据
                              |
                      人授权；智能体协助
```

公共门户描述这种关系，但不位于执行链路中。Vault 与 Design Lab 是独立仓库，并采用锁步里程碑版本。交换必须显式发生：项目可以使用 Vault 中经审查的知识和方法；经审查的项目洞见可以晋升回 Vault，而无需复制原始执行状态。

该架构使用 Git 保存紧凑、可审查的状态。大型输出、参考文献数据库、托管附件和原生工具存储留在外部，通过稳定标识和来源信息引用。
