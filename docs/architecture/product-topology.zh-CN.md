# 产品拓扑

两个核心模板都支持可选的形式化数学工作流。项目可以在自己的 Lab 启用 Lean/Mathlib，并在 Vault 中保存精确的形式化引用。工具链由项目自主选定并锁定。

产品包含两个公共组件：

```text
ResearchFabric（公共门户；非组件）
├── RVT：研究知识库模板
└── RDLT：研究设计实验室模板
```

RVT 负责跨项目语义知识、文献理解、可复用方法、术语、知识地图和项目门户。RDLT 负责具体项目的假设、方法、实验、运行证据、失败、验证和显式采纳的决策。

ResearchFabric 负责公共说明与导航。独立的私有协调仓库可以保存开发路线图和收据，但既不是公共产品表面，也不是运行时产品。逻辑成员关系不意味着文件系统嵌套或源码耦合。
