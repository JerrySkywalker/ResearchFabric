# 仓库模型

每个仓库只有一个持久角色。

| 仓库类别 | 负责 | 不负责 |
| --- | --- | --- |
| ResearchFabric | 公共架构、理念、清单与导航 | 模板源码或运行时状态 |
| 研究知识库模板 | 通用跨项目知识结构与工作流 | 项目实验或已采纳项目设计 |
| 研究设计实验室模板 | 通用可执行项目研究结构与工作流 | 跨项目规范知识 |
| 特化实例 | 自身知识或项目状态 | 模板路线图完成状态 |
| 私有模板对协调 | 路线图、模板对状态、决策、紧凑收据 | 组件源码、烟雾测试、资产 |

系统不使用子模块、子树、源码镜像或自动同步。模板演进由实例有意采用。仓库提交提供可追溯性，而科学有效性还取决于 Git 之外的方法、证据、审查和权威。
