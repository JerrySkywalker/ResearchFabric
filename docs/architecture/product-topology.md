# Product Topology

The product has two public components:

```text
ResearchFabric (public portal; non-component)
├── RVT: Research Vault Template
└── RDLT: Research Design Lab Template
```

RVT owns cross-project semantic knowledge, literature understanding, reusable methods, terminology, maps, and project portals. RDLT owns a project's hypotheses, methods, experiments, run evidence, failures, verification, and explicitly adopted decisions.

ResearchFabric owns public explanation and navigation. A separate private coordination repository may preserve development roadmap and receipts, but it is neither public product surface nor runtime product. Logical membership never implies filesystem nesting or source coupling.
