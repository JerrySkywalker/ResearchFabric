# ResearchFabric Agent Contract

ResearchFabric is a bilingual public documentation and architecture portal. It is not a Template Pair component, source mirror, monorepo, runtime service, or authority for scientific claims.

Keep English and Simplified-Chinese peers aligned. Preserve the boundaries in `components/manifest.yaml`: the Vault owns cross-project semantic knowledge; the Design Lab owns executable project research state. Do not import private coordination data, transcripts, credentials, private research, component source trees, submodules, or machine-specific paths.

Agents may propose prose and diagrams, but must not imply that agent output is evidence or an Owner/scientific decision. Git history is reviewable state, not scientific proof. Run `python scripts/check_bilingual_docs.py` and `git diff --check` for documentation changes.
