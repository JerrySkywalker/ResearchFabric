# Security

## Reporting

Please report security-sensitive findings privately through GitHub's security advisory feature when available. Do not place credentials, private research data, internal hostnames, private repository content, or exploit details in a public issue.

## Portal boundary

ResearchFabric is a static documentation portal and contains no runtime service or credential flow. Security reports about either template should identify the affected component repository. Claims about unsafe scientific practice, data provenance, or authority confusion are also welcome when they expose a concrete harmful workflow.

Public contributions must not include secrets, personal absolute paths, private coordination receipts, raw transcripts, or proprietary research evidence.
